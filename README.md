# 제1회 제주시농협 AI 공모전 — 발표 순서 추첨 · 실시간 채점 시스템

## 파일 구성
| 파일 | 역할 |
|---|---|
| `order.html` | 발표 순서 추첨 (시드 공개·검증 가능 방식) |
| `score.html` | 실시간 채점 — `?view=admin`(운영) / `judge`(심사위원) / `vote`(관람객) / `board`(전광판) |
| `config.js` | Firebase 설정·최고관리자·부문 정의 (두 페이지 공용) |
| `firestore.rules` | Firestore 보안 규칙 |

네 파일을 같은 폴더에 올려야 합니다. 예: `jejusinonghyup.github.io/ai-contest/`

---

## 1. Firebase 준비 (최초 1회, 약 10분)
1. https://console.firebase.google.com 에서 새 프로젝트를 만듭니다. (예: `jejunh-ai-contest`)
2. **Authentication → 로그인 방법**에서 다음 두 가지를 사용 설정합니다.
   - **Google** (심사위원·운영자용)
   - **익명** (관람객 투표용)
3. **Authentication → 설정 → 승인된 도메인**에 `jejusinonghyup.github.io`를 추가합니다.
4. **Firestore Database**를 만듭니다. 리전은 `asia-northeast3`(서울), 시작은 프로덕션 모드로 합니다.
5. **Firestore → 규칙** 탭에 `firestore.rules` 내용을 붙여 넣습니다. `your-admin@gmail.com`을 운영 총괄 구글 계정(소문자)으로 바꾼 뒤 **게시**합니다.
6. **프로젝트 설정 → 내 앱 → 웹 앱 추가**에서 나온 `firebaseConfig` 값을 `config.js`에 붙여 넣습니다. `SUPER_ADMINS`에도 5번과 같은 계정을 넣습니다.

## 2. 초기 설정
1. `score.html?view=admin`에 접속해 운영자 계정으로 로그인합니다.
2. **기본 설정 생성**을 누릅니다.
3. **설정**에서 다음을 입력하고 **설정 저장**을 누릅니다.
   - 심사위원: 한 줄에 `이메일, 이름` (예: `judge1@gmail.com, 홍길동`)
   - 부문별 심사 항목: 한 줄에 `항목명, 배점` 형식이며, 배점 합계가 100점이어야 합니다. 기본값은 예시이므로 실제 심사 기준으로 바꿔 주세요.
   - 비율(80/20), 인센티브(3%), 관람객 투표 척도(1~10점)

## 3. 발표 순서 추첨 (`order.html`)
1. 부문별 칸에 `팀명 | 작품명 | 1` 형식으로 명단을 붙여 넣습니다. 마지막 칸은 접수차수(1 또는 2)이며, 엑셀 3개 열을 그대로 복사해도 됩니다.
2. 부문 진행 순서를 고정할지, 부문 순서까지 추첨할지 선택합니다.
3. **🎲 발표 순서 추첨**을 누르면 현장 화면에 한 팀씩 공개됩니다.
4. **이 순서로 확정 · 심사 시스템에 반영**을 누르면 관리자 로그인이 필요합니다. 반영하면 채점 화면에 팀 목록이 자동으로 들어갑니다.

### 공정성 장치
- 순서는 `시드 + 정렬된 명단`만으로 결정됩니다. SHA-256 기반 Fisher–Yates 셔플을 사용합니다.
- 확정 기록(시드, 명단 지문, 결과)은 공개 이력에 남고 수정·삭제할 수 없습니다. 누구나 **검증** 버튼으로 재계산해 볼 수 있습니다.
- 심사 점수가 한 건이라도 들어오면 순서를 다시 반영할 수 없습니다.

## 4. 행사 당일 운영 흐름
| 단계 | 운영자 (`?view=admin`) | 심사위원 (`?view=judge`) | 관람객 (QR → `?view=vote`) |
|---|---|---|---|
| 발표 시작 | **발표 시작** 또는 **다음 팀 ▶** | 해당 팀 채점표가 자동으로 열림 | "잠시 기다려 주세요" |
| 발표 종료 | **▶ 관람객 투표 열기** | 항목별 점수 입력 → 제출 | 1~10점 투표 (기기당 1표, 변경 가능) |
| 다음 팀으로 | **⏹ 투표 닫기** → (선택) **🔒 채점 마감** | 마감 전까지 수정 가능 | 다음 팀 대기 |

- 전광판(`?view=board`)은 대형 화면에 띄웁니다. 운영자 계정 로그인이 필요합니다. 투표가 열리면 QR이 자동으로 표시됩니다.
- 시상 전까지 점수를 숨기려면 **🙈 전광판 점수 숨기기**를 누릅니다. 숨기는 동안 전광판에는 심사 진행 현황만 보입니다.
- 결과는 **CSV 다운로드**로 받을 수 있습니다. 심사위원별 점수와 환산 내역이 모두 포함됩니다.
- 리허설 뒤에는 **점수·투표 전체 삭제**로 초기화합니다. 참가팀과 설정은 유지됩니다.

## 5. 점수 계산식
```
심사 점수   = 심사위원 총점(100점 만점)의 평균
관람객 점수 = 관람객 투표 평균 × (100 ÷ 투표 척도)      예) 10점 척도에서 평균 8점 → 80점
합계        = 심사 점수 × 80% + 관람객 점수 × 20%
최종 점수   = 합계 × 1.03  (1차 접수팀)  /  합계 (2차 접수팀)
→ 소수 셋째 자리에서 반올림하여 둘째 자리까지 표시
```
예: 심사 평균 85점, 관람객 평균 8/10점 → 85×0.8 + 80×0.2 = **84.00점**. 1차 접수팀이면 84 × 1.03 = **86.52점**입니다.

- 순위는 부문별로 산정합니다. 동점이면 심사위원 평균이 높은 팀이 상위이며, 그래도 같으면 공동 순위로 표시합니다.
- 관람객 투표가 0표인 팀은 관람객 점수 0점으로 계산됩니다.

## 참고
- 관람객 중복 방지는 기기(브라우저)마다 생성되는 익명 계정 기준입니다. 시크릿 창을 쓰면 다시 투표할 수 있습니다. 엄격한 통제가 필요하면 별도 투표권(코드) 방식을 검토하세요.
- `config.js`를 ES 모듈로 불러오기 때문에, 파일을 더블클릭해 `file://`로 열면 동작하지 않습니다. GitHub Pages나 로컬 서버(`npx serve`)로 열어 주세요.
